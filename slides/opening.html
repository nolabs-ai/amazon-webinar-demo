The problem

An agent should not inherit every power of its credential

  • Autonomous agents need real credentials to do real work.
  • Those credentials are almost always broader than the task.
  • On remote infrastructure there is no human watching to click "deny".
  • Prompt instructions are not an authorization boundary.

What is nono

A capability sandbox for agents and their tools

Open source, kernel-enforced (Landlock on Linux, Seatbelt on macOS). Everything is denied unless a profile grants it.

01

Micro tool sandboxing

Each command (git, gh, ssh) runs in its own sandbox with its own files, network and argument policy.

02

Credentials per tool

A secret is bound to one tool. The agent sees a phantom value; nono injects the real one at the proxy.

03

Endpoint policy

Credentialed requests are allowed by HTTP method and path. Merge, delete and GraphQL can be denied outright.

04

Audit every decision

Every allow and deny is recorded, so you see what an agent attempted, not just what it reported.

nono profile: reviewer

Reviewer agent

Reads the issue and diff, reruns tests, posts a verdict comment. Cannot modify anything.
